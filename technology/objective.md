# Technology

## Desired outcome
Turn laboratory discoveries into reusable tools that increase Oasis's practical capacity to act.

## Programs
- Graph Browser: general-purpose graph navigation, composition, and editing; the existing implementation remains at `graph-browser/` during migration.
- Graph agents and runtime: bounded execution, observation, and tool integration.
- Graph Lang implementations: practical interfaces to the laboratory's semantics.

## Next move
Design a nonbreaking graph-entry adapter for the current filesystem-backed Graph Browser, with tests that preserve existing objective editing.
