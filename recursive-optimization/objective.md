# Recursive Optimization

## Desired outcome
Oasis operates through its own objective graph, recursively decomposing problems, testing competing solutions, and allocating resources toward approaches that demonstrate measurable success.

## Implementation guidance
- The tree is Oasis, not a report about Oasis. Nodes carry outcomes, metrics, evidence, instructions, and decision rights.
- Humans and agents may decompose objectives and fork A/B approaches.
- Compare approaches using evidence of progress toward their parent objectives, not activity counts.
- Allocate resources toward demonstrated performers while preserving some exploratory budget for uncertain upside.
- Preserve inspectable results; reconcile agent work with current founder instructions before commits.
- Apply the same process recursively to improve Oasis's own intelligence and execution.
