# Oasis

Oasis is a living objective graph rooted in [objective.md](objective.md).

The Graph Browser MVP opens the repository as recursive, editable windows.

```sh
npm run setup
npm run dev
```

Requires Node.js 22.12+ and Git. Open the local URL printed by Vite.

See [Graph Browser instructions](graph-browser/mvp/README.md) for editing, Git persistence, verification, and current limits.
