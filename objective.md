# O0 — Build Graph Browser and achieve product-market fit

**Owner:** Founder  
**Status:** Active  
**Depth:** 1 of 3

## Objective

Build and launch a browser-based environment for exploring, editing, and operating live organizations as graphs. Use Oasis itself as the first proving ground, then iterate with real teams toward product-market fit.

## Approved child objectives

1. [Graph Lang](graphlang/objective.md) — provide the general recursive, functional graph-computation foundation.
2. [Graph Browser](graphbrowser/objective.md) — route, render, navigate, edit, and persist live graphs in a browser.
3. [Product validation](validation/objective.md) — dogfood, host, observe usage, and learn from external teams.

## Outcome evidence

A user can navigate, modify, save, and revisit a real organizational graph; external teams can try the hosted product; repeat usage and qualitative feedback inform prioritization. Product-market fit is a goal to validate, not a status inferred from shipping features.

## Governance

Founder-authored objectives are authoritative. Agents may propose new key results, not install them without founder review. Depth 3 is the default limit. Technical objectives should identify the user capability they enable.
