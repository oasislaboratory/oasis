# Upper Leadership — Specify a minimal graph computation contract

Define a small, explicit candidate language foundation grounded in the [source baseline](../01-source-baseline/objective.md). Mark candidate decisions as proposals until accepted; preserve founder direction.

Acceptance criteria:
- State graph objects and representation invariants, directedness, identity, allowed edges, and the distinction between data and executable structure.
- Define the smallest coherent evaluation model, including inputs, outputs, environment lookup, errors, and termination/resource boundaries.
- Provide hand-worked positive and negative examples with unambiguous expected outcomes, and explain how examples follow the rules.
- Link each rule to current evidence or an explicit proposed change; record unresolved consequential choices for founder review.
